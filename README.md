# منظومه شمسی · Solar System

Interactive 3D solar system (React + three.js). Persian (RTL) by default, English at `?lang=en`.

```bash
npm install
npm run dev
```

- Fonts: copy your `PeydaWeb-*.woff2` files into `public/fonts/`.
- Textures: surfaces are procedural. For real NASA imagery, put `<id>.jpg` files in `public/textures/` and set `USE_LOCAL_TEXTURES = true` in `src/config.js`.
- Data: NASA/JPL orbital elements and NSSDC fact sheets, Wikipedia, SIMBAD (see the Sources dialog in the app).
